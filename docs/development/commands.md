# Commands

- `make install`: install frontend and backend dependencies.
- `make dev`: start local infrastructure and print dev instructions.
- `make web`: start the Next.js frontend.
- `make api`: start the FastAPI backend.
- `make chunker-build`: compile the local Node chunking companion.
- `make infra-up`: start PostgreSQL and Qdrant.
- `make infra-down`: stop local infrastructure.
- `make migrate`: apply Alembic migrations.
- `make test`: run frontend and backend tests.
- `make lint`: run ESLint and Ruff.
- `make format`: format frontend and backend code.
- `make typecheck`: run TypeScript and mypy checks.
- `make check`: run the full validation suite.
- `make clean`: remove local build and cache artifacts.
